# findar-app

**Findar** is a Flutter mobile app for selling and renting homes.

It helps **sellers and real estate agencies** create listings for properties like **houses, apartments, villas, and studios**, and helps **buyers/renters** easily discover the right place and reach out to the owner.

## Landing page
https://fin-dar-website.vercel.app/

## What you can do

### For sellers & agencies
- Create and publish property listings
- Add key details (price, location, photos, and description)
- Manage and update listings

### For buyers & renters
- Browse available properties
- Filter listings to match what you’re looking for
- Save/bookmark favorite listings
- Contact the owner/agent directly from a listing
